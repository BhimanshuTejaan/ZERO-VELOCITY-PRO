Zero Velocity - Quick Start Guide

Follow these 7 simple steps to install and activate your plugin.

1

Install ZXP Installer

Open folder 1. Install ZXP Installer and launch Get ZXP Installer.html to download the free aescripts ZXP Installer utility.

2

Install ZeroVelocity-v1.0.0.zxp

Launch ZXP Installer, then drag and drop 2. ZeroVelocity-v1.0.0.zxp into the installer window.

3

Install Recommended Fonts

Open folder 3. Fonts to review the font setup guide for Inter and Montserrat typography presets.

4

Restart Adobe After Effects

Close and restart After Effects to allow the extension manager to load the newly installed plugin files.

5

Open Zero Velocity

Inside After Effects, navigate to top menu: Window ➔ Extensions ➔ Zero Velocity.

6

Activate Your License

Enter the license key received via email or purchase screen (e.g. ZV-XXXX-XXXX-XXXX) and click Activate License.

7

Start Creating Captions

Import your one-word SRT file, customize styling presets, and generate animated captions on your After Effects timeline!
