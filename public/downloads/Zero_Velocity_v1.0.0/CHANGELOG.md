# Zero Velocity Release Notes

## Version 1.0.0 (Official Release)

### Key Features
- **One-Word SRT Import & Parsing**: Blazing-fast one-word SRT parser for modern video editing.
- **Live In-Plugin Preview Renderer**: Real-time browser preview renderer for caption blocks, hero words, and support text.
- **After Effects Engine Bridge**: Automated comp creation, text layer formatting, and transform positioning.
- **Dynamic Layout & Spacing Controls**: Adjustable vertical spacing, hero size ratio, and preset styles.
- **Word Style Editor**: Interactive hero & accent role toggling on individual words.
- **Enterprise Licensing System**: Fast online key activation with Firebase Admin SDK backend.
- **Offline Grace Period**: Cryptographically signed Ed25519 asymmetric offline validation (7-day offline grace period).
- **Hardened Security & Performance**: Pre-compiled ExtendScript JSXBIN binary, obfuscated production JS, and lightweight session checkpoints.
