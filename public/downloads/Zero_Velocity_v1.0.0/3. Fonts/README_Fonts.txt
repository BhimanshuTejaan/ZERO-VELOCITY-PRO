====================================================================
ZERO VELOCITY - RECOMMENDED CAPTION FONTS & INSTRUCTIONS
====================================================================

Zero Velocity comes pre-configured with industry-standard caption design presets.
To ensure your captions render identically to the live preview, we recommend installing the following fonts:

1. RECOMMENDED FONTS:
   - Inter (Bold / Extra Bold / Black) - Free Google Font
     Download: https://fonts.google.com/specimen/Inter
   - Montserrat (Bold / Extra Bold / Black) - Free Google Font
     Download: https://fonts.google.com/specimen/Montserrat
   - Kaleko 105 (Corporate Clean Preset) - Optional Commercial Font

2. HOW TO INSTALL FONTS ON WINDOWS:
   - Select the downloaded .ttf / .otf font files.
   - Right-click and choose "Install for all users" (or "Install").
   - Restart Adobe After Effects to load the new fonts.

3. HOW TO INSTALL FONTS ON macOS:
   - Double-click the downloaded .ttf / .otf font files.
   - Click "Install Font" in Font Book.
   - Restart Adobe After Effects to load the new fonts.

Note: No fonts have been substituted or modified in the plugin presets.
If a recommended font is missing on your machine, After Effects will automatically fallback to your system default font.
